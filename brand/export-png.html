DepControl icon export

Open this file in a browser and save each size. It runs offline — the artwork is inlined below, nothing is fetched.

GitHub OAuth app takes the 512 (it wants at least 200×200 and will not accept an SVG). Flutter web wants 192 and 512 in frontend/web/icons/; the favicon is already wired up as an SVG, which every current browser reads, so the 32 is only for older ones.
